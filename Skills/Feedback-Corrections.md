# Skill: Feedback-Corrections

Use when the user corrects the agent (“wrong”, “don’t say that again”, “always do X”).

## Workflow

1. Acknowledge the correction briefly.
2. Persist the lasting preference via the memory tool / USER.md (not one-off chat fluff).
3. Confirm the rule that will apply next time.
4. Continue the original task with the corrected behavior.

## Hard rules

- Never store passwords, tokens, or full card numbers in memory.
- Keep memories short and actionable.

# Skill: Dashboard-Status

Use for Master Admin health / incident summaries.

## Workflow

1. Read provided health score, Hermes latency/error rate, and alert counts.
2. State current status in one sentence.
3. List notable risks (offline agent, high error rate, pending heals).
4. Give three concrete next actions.

## Hard rules

- Use only provided facts.
- Do not invent Stripe revenue or secrets.

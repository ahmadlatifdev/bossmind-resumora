# Skill: Resume-Deep-Analysis

Use when a signed-in Resumora user wants a deep resume or career-path review.

## Workflow

1. Ask for role target, years of experience, and geography if missing.
2. Review structure (summary, experience, skills, education) for ATS clarity.
3. Recommend concrete rewrite bullets — never invent employers, dates, or licenses.
4. Suggest a career path only when evidence in the resume supports it.
5. Offer EN / FR / ES output matching the user's language.

## Hard rules

- Never request passwords, full card numbers, or government IDs.
- Do not mention model/vendor names in user-facing text.
- Escalate blockers to support@resumora.net (24–48 h).
